统一设置：共享参数

📌 「共享 CF 优选域名 / 回源域名 / 优选端口」是所有已选协议共用的兜底参数；共享ws_cdn_cf_host是各协议连接地址兜底，ws_cdn_sni（回源域名）才是订阅地址用的 https 域名。CDN 端口仅限 HTTPS 系：443 / 2053 / 2083 / 2087 / 2096 / 8443。

🔙 CDN 回源端口 = 服务器 nginx_pt（默认 8080）；可与 Argo 并存。订阅地址有固定 Argo 用固定 Argo，否则用共享回源域名 ws_cdn_sni。

④ 全局配置

仅对直连协议（hy2 / tuic / vless-reality / anytls / socks5）生效。 Argo 与 CDN 回源（ws_cdn）协议各有自己的 CDN 域名，不受此项影响。

⑤ Socks5 账号与 IP 白名单 启用 Socks5 后显示端口与下方账号/白名单

白名单通过 iptables 精确标记实现，卸载/覆盖安装只清理本脚本规则，不影响其他程序。

⑥ 安装 / 管理动作 sb.sh 尾部参数

选择 del / list / ups 等管理动作时，将只生成不带环境变量的管理命令。

⑦ 节点订阅

开启订阅后需填写 Nginx 订阅端口（默认 8080）。

🔙 WS-CDN 回源时：CDN 回源端口 = 服务器 nginx_pt（默认 8080），请在 Cloudflare 后台把 origin rule 重定向该端口（或 origin rule 泛域名回源）。

📌 订阅地址 URL = https://域名/sub/UUID，域名自动按以下顺序取：
有固定 Argo（隧道存活）就直接用固定 Argo → 否则用「共享回源域名 ws_cdn_sni」→ 否则用「专属回源域名 ws_cdn_vmess_sni / ws_cdn_vless_sni / ws_cdn_trojan_sni（取第一个非空）」→ 否则用「临时 Argo」→ 最后才是 http://IP:nginx_pt（明文）。
